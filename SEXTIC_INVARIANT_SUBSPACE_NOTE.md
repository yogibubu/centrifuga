# Sextic Invariant Subspace Note

## Statement

The present CeDiTT sextic algorithm is stronger than a merely practical
coordinate transform.  It is based on a **representation-independent
five-dimensional operator subspace** `S_6` inside the degree-six rotational
polynomial space.

In Watson's `S` reduction, sextic constants are represented as a 7-component
vector

`H_S = (H_J, H_JK, H_KJ, H_K, h_1, h_2, h_3)^T`.

The algorithm identifies a canonical rank-5 subspace

`S_6 ⊂ R^7`

and decomposes any sextic parameter vector as

`H_S = B_rep sigma + r`

where:

- `sigma ∈ R^5` are the coordinates on the invariant sextic subspace,
- `B_rep` is the `7 x 5` representation matrix for the chosen axis system,
- `r ∈ R^7` is the residual in the complementary 2D sector.

For internally consistent sextic constants generated inside the model,
`r = 0` to numerical precision.

## Canonical Operator Basis

In the symbolic derivation implemented in `derive_sextic_transform.py`, the
invariant subspace is generated by five degree-six rotational polynomials:

- `sigma_1 = w_1 + 2 w_2 - w_5`
- `sigma_2 = 3 w_3 + w_6`
- `sigma_3 = w_4 - w_7`
- `sigma_4 = w_1 - w_3 + 2 w_5`
- `sigma_5 = w_2 + w_7`

where `w_i` are Watson's sextic basis operators in a fixed reference
representation.

Equivalently, in explicit monomial form:

- `sigma_1 = 3 Ja^6 + 7 Ja^4 Jb^2 + 7 Ja^4 Jc^2 + 5 Ja^2 Jb^4`
  `         + 10 Ja^2 Jb^2 Jc^2 + 5 Ja^2 Jc^4 + Jb^6 + 2 Jb^4 Jc^2`
  `         + 4 Jb^2 Jc^4 + Jc^6`
- `sigma_2 = 3 Ja^6 + 3 Ja^4 Jb^2 + 3 Ja^4 Jc^2 + Ja^2 Jb^2 Jc^2`
- `sigma_3 = Ja^6 - Ja^2 Jb^4 + Ja^2 Jc^4`
- `sigma_4 = 2 Ja^4 Jb^2 + 2 Ja^4 Jc^2 + 3 Ja^2 Jb^4`
  `         + 6 Ja^2 Jb^2 Jc^2 + 3 Ja^2 Jc^4 + Jb^6 + 5 Jb^4 Jc^2`
  `         + Jb^2 Jc^4 + Jc^6`
- `sigma_5 = Ja^6 + 2 Ja^4 Jb^2 + 2 Ja^4 Jc^2 + 2 Ja^2 Jb^4`
  `         + 2 Ja^2 Jb^2 Jc^2`

These basis elements are not individually invariant under cyclic relabelings of
the principal axes, but their **span is invariant**.

## Representation Theory Content

Let `P_rep` denote the cyclic relabeling of the principal axes corresponding to
the `I`, `II`, or `III` representation.  Then

`P_rep(S_6) = S_6`

and therefore the representation change acts by a linear `5 x 5` map on the
canonical coordinates `sigma`.

Operationally, if `B_I`, `B_II`, `B_III` are the matrices expressing the same
subspace basis in the Watson sextic coordinates of each representation, then

`H_R = B_R sigma`

and

`T_6(R -> R') = B_R' pinv(B_R)`.

This is the mathematical basis of the validated CeDiTT sextic transform.

## Consequence

The CeDiTT sextic `5+2` decomposition is therefore not only a practical
parameterization.  It is the decomposition of a 7-component sextic Watson
vector into:

- a canonical five-dimensional invariant subspace carrying the physical content
  of the modeled sextic transform,
- plus a complementary two-dimensional residual sector.

What is still missing, if desired for future work, is a more compact geometric
interpretation of `S_6` analogous to the quartic `Tau'` tensor.  At present,
the strongest rigorous statement is the existence of this invariant
five-dimensional operator subspace, not the existence of a single simple tensor
object of rank two.
