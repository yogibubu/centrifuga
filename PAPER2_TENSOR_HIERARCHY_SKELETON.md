It should be treated as the conceptual skeleton of the full VPT4 / nonlinear-tensor follow-up.

## 1. Inverse inertia expansion

The starting point is the inverse inertia tensor as a function of vibrational coordinates:

I^{-1}(Q) = I_0^{-1} + \mu_1 Q + \tfrac12 \mu_2 Q^2 + \cdots

with

- \mu_1 = d(I^{-1})/dQ
- \mu_2 = d^2(I^{-1})/dQ^2

In the current code and manuscript, \mu_1 is the first-level geometric object and
\mu_2 opens the next intrinsic tensor level.

## 2. Linear tensor sector

The first paper shows that standard quartic and standard sextic centrifugal distortion
constants belong to the same linear tensor sector generated by \mu_1, together with
Coriolis couplings and vibrational frequencies.

Schematically,

C^(4), C_std^(6) = P F(\mu_1)

where

- P = projection onto Watson parameters
- F = tensorial combinations built from first-level objects

This is the minimal linear tensor sector.

## 3. First nonlinear layer

When cubic force constants \phi_3 enter, new sextic contributions appear that are not
contained in the purely first-level geometric sector. Schematically,

C^(6) = P [ F(\mu_1) + G(\mu_1, \phi_3) ]

The mixed term G(\mu_1, \phi_3) is the first nonlinear layer of the hierarchy.

## 4. Second geometric level

When \mu_2 enters, contributions of the H22 type appear. Schematically,

C^(4) = P [ F(\mu_1) + H(\mu_2) ]

In the first paper this is resolved concretely through

\mu_2 = B(\mu_1) - N

with N the first genuinely new intrinsic geometric tensor.

## 5. General hierarchical form

The emerging structure can be written schematically as

C = P [ F_1(\mu_1) + F_2(\mu_1, \phi_3) + F_3(\mu_2) + \cdots ]

Each term corresponds to a distinct tensorial level in the hierarchy.

## 6. Representation transport

In the tensor formulation, the primitive tensor content is transported between
representations by a representation operator R:

T' = R T

and spectroscopic constants are recovered by projection:

C' = P R T

Thus centrifugal distortion constants should be viewed as coordinates of transported
tensor objects rather than as primitive quantities.

## 7. Conceptual summary

The first paper establishes that:

- a minimal linear tensor sector exists,
- it is generated by \mu_1,
- it produces standard quartic and standard sextic constants,
- the first breakdown arises when higher tensor layers enter.

The second paper should turn this into a full nonlinear tensor hierarchy for the
VPT4 problem.
